# Chat 周报更新：本地实施与验收

日期：2026-10-23。Flutter 3.47.5 / Dart 3.13.4。保留宿主固定的 Apple UI 分支 `e87d7b4a`，在 `feat/chat-weekly-security-20261023` 实施。详细[计划](../../plans/2026-10-23-chat-weekly-upgrade.md)、[安全协议](../../security/mini-app-policy-v1.md)、[外部验收](EXTERNAL_ACCEPTANCE.md)。

## 已实施

- P0：原始URL规范化与同源限制、OAuth精确回跳和随机state校验、SDK最低版本/denylist、Ed25519签名策略和启动参数、有效期/audience/app/目标绑定、本地持久nonce防重放、文档级原生桥nonce和异步回包复核。扫码外部入口先显示登记服务方与域名。无远程配置时只支持内置基础入口，业务链接必须签名。
- Markdown：默认不加载远程图片或打开链接；用户可查看源文、确认外部链接、点击加载单图。HTTPS下载不跟随重定向，最多2 MiB，加密附件验证后展示；大文本分页限制解析量。
- 大文件：文件路径/流采用磁盘流式Matrix v2加密；取服务端与客户端限额较小值，宿主能力上限1GiB，服务端限额未知时回退50MiB。内存及定时附件仍限50MiB。图片/视频及缩略图通过SDK加密，不明文回退。
- 接收端：普通附件下载传入加密参数，先验证密文SHA-256再流式解密，成功后才发布最终文件，提供系统打开/保存面板。实际下载字节最多1GiB，不跟随重定向。加密PDF走验证后的下载/系统打开，内置PDF预览仍仅用于非加密文件。
- NFC：扫描页读取NDEF URI，支持取消、超时及重复回调抑制；接入iOS/Android原生声明，复用扫码路由和登记服务方确认。
- 测量与试点工具：无内容/身份的媒体阶段事件、去重与漏报计算；NFC/QR/link对照试验、匿名指标及七日复用汇总。没有建设或宣称上线完整商户后台。

## 未宣称完成的验收

统一维护在 `OPEN_ISSUES.md`：SEC-006、MEDIA-006、EXPERIMENT-001；新文案语言覆盖沿用QA-006。缺少生产策略服务/公钥/升级地址、手机和外部浏览器的安全回放、真实视频/HDR/弱网测量、遥测收集器、商户/实体标签与七天数据。200个零失败样本的单侧95%失败率上限约1.49%，不能证明 <0.1%。不以“接口已实现”代替这些验收。

外部实施顺序：资料齐备后先部署并演练策略禁用/恢复；然后在隔离Matrix测试房间完成移动端媒体样本；再招募3–5个商户做平衡分配的NFC/QR/link试点，满七日后汇总复用并取得至少两家继续使用的决定。具体步骤、字段和命令均在[外部验收](EXTERNAL_ACCEPTANCE.md)。本轮没有TestFlight上传、APK发布或生产切换。
